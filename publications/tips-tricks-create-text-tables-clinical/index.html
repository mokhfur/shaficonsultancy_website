Tips and Tricks to Create In-text Tables in Clinical Trial Reporting Using SAS

PhUSE conference, Edinburgh 2017 · By Md. Jabrul Islam & Shafi Chowdhury, Shafi Consultancy

Download PDF
Share
Abstract

Although In-text tables were produced by Medical Writers in the past, increasingly the task is being handed over to the programmers. In some cases they are pre-planned and produced at the same time as when the other TLFs are produced for the CTR appendix, however, in most cases they are still defined towards the end of the trial and this can be really time consuming at the busiest period of a programmer’s resource. This paper will show a step-by-step procedure on how to create an In-text table using SAS ODS RTF and directly copy it into an MS Word document with PROC REPORT and PROC TEMPLATE so that it is in the structure required by the Medical Writers. This will arm the programmers with all the tools to make quick updates as and when required and set up templates that can be available for use in all trials.

Introduction

Programmers used to create tables in Word for Clinical Trial Reports (CTR) by using the SAS ODS RTF destination. Although there are many features of SAS ODS RTF, programmers struggle to utilize its benefits for generating efficient output. In this paper, we will present some basic methods to help the programmers create tables in Word and also demonstrate the process for using the PROC TEMPLATE with ODS RTF and PROC REPORT. The key points to be discussed in this paper are:

- Syntax and Different statements of PROC TEMPLATE - Assigning Header, Title and Footnote of Word table - Page numbering (e.g. Page X of Y)

Example 1: Summary of Baseline Characteristics

PROC Template

In the template, we are creating a new style template named RTF1 using the parent style RTF from the SAS catalog. In the new style template, we defined all the attributes needed for the table in Word, e.g. title and footnote fonts, body fonts, attributes for row headings and column headings, background color, link color, internal and external border color and thickness, and page settings for display result.

PROC TEMPLATE;

DEFINE STYLE Styles.RTF1; /* Defining Template Name */

  PARENT = Styles.RTF;

/* Parent Style Template */ REPLACE fonts / /* Titles from TITLE statements */ 'TitleFont' = ("Calibri, Arial, Times Roman",12pt) 'StrongFont' = ("Calibri, Times Roman",10pt, Bold)

'EmphasisFont' = ("Calibri, Times Roman",10pt, Italic) 'headingEmphasisFont' = ("Calibri, Times Roman",11pt, Bold Italic) /* Table column and row headings */ 'headingFont' = ("Arial, Times Roman",10pt, Bold) /* Data in table cells */ 'docFont' = ("Arial, Times Roman",10pt) /* Footnotes from FOOTNOTE statements */ 'footFont' = ("Calibri, Times Roman",10pt) 'FixedEmphasisFont' = ("Courier",9pt, Italic) 'FixedStrongFont' = ("Courier",9pt, Bold) 'FixedHeadingFont' = ("Courier",9pt, Bold) 'BatchFixedFont' = ("Courier",6.7pt)

'FixedFont' = ("Courier",9pt);

REPLACE color_list / 'link' = blue /* links */ 'bgH' = white /* row and column header background */ 'fg' = black /* text color */

'bg' = white;

/* page background color */; CLASS Header / /* Header Attributes */ foreground = black verticalalign = top; CLASS TitlesAndFooters / /* Title and Footnote Attributes */ font = Fonts('TitleFont') color = color_list('link') textalign = left frame = void; REPLACE Body from Document / /* Page setting for display results */ bottommargin = .7in topmargin = .7in rightmargin = .7in leftmargin = .7in protectspecialchars = off; REPLACE Table from Output / frame = box /* outside borders: void, box, above/below, vsides/hsides, lhs/rhs */ rules = all /* internal borders: none,all,cols,rows,groups */ borderwidth = 1pt bordercolor = color_list('fg') width = 100% /* the width of the borders and rules */ asis = on;

  END;

If anyone wishes to see all the SAS built-in style templates then they can find these using the following code segment:

PROC TEMPLATE;

LIST styles;

ODS RTF and PROC Report

The following program will create the baseline characteristics summary table named t_demo.rtf (Figure-1) using the above template (styles.rtf1) and the result from the PROC REPORT.

* Define page orientation, option to not print date and page number *; * ODS destination is closed for the Listing *; * An escape character is specified to perform in-line formatting *;

OPTIONS NODATE NONUMBER ORIENTATION=PORTRAIT;
ODS LISTING CLOSE;
ODS ESCAPECHAR = '^';

* Specify destination path for RTF file and select a style template *; * Define device type for RTF (only supports: SASEMF, PNG and JPEG) *; * Define titles, footnotes and page numbers (i.e. page x of y)*;

ODS RTF FILE="&pathname./t_demo.rtf" STYLE=styles.rtf1 DEVICE=SASEMF;
TITLE 'Table: Patients baseline characteristics';
FOOTNOTE J=CENTER 'Page ^{thispage} of ^{lastpage}';

* Define PROC REPORT procedure statements *; * Include conditional format for specific rows, columns, footnotes *;

PROC REPORT DATA=final HEADLINE LS=140 PS=50 SPACING=3 SPLIT='$';

COLUMN (decodeord block decode col1 col2 coltot);

  DEFINE decodeord / ORDER ORDER=INTERNAL NOPRINT;
  DEFINE block     / ORDER ORDER=INTERNAL NOPRINT;
  DEFINE decode    / ' ' FLOW STYLE={WIDTH=27%};
  DEFINE col1      / "DummyRed$(N =&col1.)" WIDTH=26 STYLE={WIDTH=12%};
  DEFINE col2      / "DummyGreen$(N =&col2.)" WIDTH=26 STYLE={WIDTH=12%};
  DEFINE coltot    / "Total$(N =&coltotal.)" WIDTH=26 STYLE={WIDTH=10%};

COMPUTE decode;

     IF decodeord=0 THEN
        CALL DEFINE (_col_, "STYLE","STYLE={FONT_WEIGHT=BOLD}");
     IF decode =: "  " THEN
   CALL DEFINE (_col_, "Style", "STYLE={INDENT=0.2in}");
     IF decode =: "    " THEN
   CALL DEFINE (_col_, "Style", "STYLE={INDENT=0.4in}");
     IF block ne 1 THEN
   CALL DEFINE(_row_, "STYLE","STYLE={BORDERBOTTOMCOLOR=white}");
   ENDCOMP;

Compute After/

STYLE= {BORDERLEFTCOLOR=white BORDERRIGHTCOLOR=white

             BORDERBOTTOMCOLOR=white};

LINE @0 "Sources: ADSL";

  ENDCOMP;

* Close ODS destination for RTF and open destination for Listing *; * Reset options for date and page number *;

ODS RTF CLOSE;
ODS LISTING;
OPTIONS DATE NUMBER;

Conclusion

In this paper, we have shown how easily the In-text tables can be created for a CTR. By following the examples provided in this paper, a user can produce the In-text tables within a short period of time by using the TEMPLATE procedure rather than by designing the table in the REPORT procedure. Also, this paper will help users to customize the header, title, footnotes, page numbering (e.g. Page x of y), results attributes, as well as the structure for different layouts of Word tables for clinical trials.
